## 发现与修复

模板基线的所有必需检查通过。初次受沙箱限制的 tsx IPC/安装网络失败属于执行环境限制，取得执行权限后原命令通过，没有关闭检查。

本次实现阶段发现并修复：

1. 自定义标题区与 Markdown H1 重复：在 VuePress 页面 SFC 中去掉正文 H1，源文件保持唯一 H1，标题区统一渲染。
2. 原滚动插件与新目录并存，滚动时改写 hash，同时新目录计算当前章节；移除重复管理，统一在目录计算。活动字体不再改变字宽，点击滚动期间稳定选中目标，ResizeObserver 处理正文重排。
3. CSS 的 scroll-margin 不会自动进入 Vue Router 的滚动坐标，导致锚点被固定栏盖住：客户端 scrollBehavior 显式读取对应偏移，并尊重减少动效设置。
4. 搜索建议需要两次 Esc 且缺少焦点恢复：采用已确认的简洁弹层，补齐一次关闭、焦点返回和明确 Tab 循环。
5. 默认主题逻辑内边距影响手机正文：共享页面覆盖为统一 gutter；人物“篇目”标题继承默认 H2 边线造成重复，已去除。
6. 390px 宽表格没有页面溢出，却把列压到约 53px：增加共享单元格最小宽度，确保宽表格真实横向滚动而不是逐字竖排，并加入浏览器断言。
7. 元数据热更新可能重置页面归属：更新时重新聚合 catalog、写页面数据与搜索归属；测试实际 VuePress createPage/update hook。
8. 测试自身的 VuePress 初始化主题、钩子类型与手机隐藏目录定位问题也已修正，没有通过跳过测试规避失败。

模板已有超过 500 kB 的图示运行时分包警告，以及 NO_COLOR/FORCE_COLOR 环境提示；保留警告，未调整阈值掩盖它们。
